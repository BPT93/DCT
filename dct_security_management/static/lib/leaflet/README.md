# Leaflet 1.9.4

Bundled under the BSD 2-Clause license in `LICENSE`.

Sources: https://leafletjs.com/download.html and https://github.com/Leaflet/Leaflet/tree/v1.9.4/dist
The minified script is the upstream release file from https://unpkg.com/leaflet@1.9.4/dist/leaflet.js.

No map provider is configured by default. The backend loads these files locally.
Map tile requests occur only after the user configures an HTTPS tile URL and attribution.
Configure a provider whose terms permit your expected usage; provider tokens, quotas,
privacy notices, and map attribution remain the administrator's responsibility.
Site pins are fixed site coordinates, never live guard locations. A native site list
remains usable without a provider or when tiles cannot be loaded.
