# Captured report samples

These 16 PDFs were printed from the running application on 2026-10-03 using
fictional records in a disposable Odoo 19 Community database. Each of the eight
report actions has an English (`en_US`) and Arabic (`ar_001`) sample.

The company name and logo are the configured defaults in that test database.
Customer names, record descriptions and generated snapshots retain their stored
language; report labels and layout follow the printing user's language.

The files are documentation only. Installing the addon does not load their
fictional records. See `../VALIDATION.md` for the workflow and rendering evidence.
